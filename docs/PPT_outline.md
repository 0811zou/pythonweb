# 农产品溯源与助农平台 —— 答辩提纲

## 一、项目背景与痛点（2-3 页）
- 传统农产品流通：信息不对称、信任缺失、农民议价能力弱
- 消费者需求：食品安全、产地溯源、绿色认证
- 政策导向：数字乡村、乡村振兴、农业数字化转型
- 平台定位：连接农户与消费者的可信溯源电商平台

## 二、系统架构与技术栈（2-3 页）
- 前端：HTML/CSS/JavaScript · Django Templates
- 后端：Django 4.2+ · Django REST Framework
- 数据库：SQLite（开发） / PostgreSQL（生产）
- 溯源核心：二维码 + 区块链式批次追踪（ProductBatch）
- 部署：Docker · Nginx · Gunicorn

## 三、核心功能模块（4-5 页）
1. **用户系统**：农户注册/认证、消费者注册、管理员后台
2. **产品管理**：农户发布产品、分类、定价
3. **批次溯源**：每个批次独立二维码、种植/收获/质检信息上链
4. **订单系统**：在线下单、线下付款凭证上传、订单状态流转
5. **补贴申请**：农户在线申请、后台审批流程
6. **农技培训**：培训内容发布、农户在线学习
7. **评价体系**：消费者评价、农户信用积累
8. **物流追踪**：订单物流事件记录与展示

## 四、溯源流程演示（2-3 页）
1. 农户录入批次信息（产品 → 批次绑定二维码）
2. 二维码生成与打印（贴于产品包装）
3. 消费者扫码 → trace_view → 完整溯源信息展示
4. 信息维度：产地、农户、收获日期、质检报告、物流记录
